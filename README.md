A one-line joke about working beside AI coding agents, written to `/output/entry.txt` by a deterministic Python program for the [make.fun competition](https://make.fun/c/the-joke-about-the-demo-20261121-0551).

> My coding agent fixed the demo bug live — by deleting the demo.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

The program uses only the Python standard library, needs no network, and writes the same joke on every run.
